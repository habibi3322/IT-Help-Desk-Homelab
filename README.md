# IT Help Desk Home Lab

## Overview

This repository documents my hands-on IT Help Desk home lab. I built this environment to gain practical experience with Windows administration, networking, Active Directory, user management, troubleshooting, and common technical support tasks.

Rather than only studying these technologies theoretically, this lab allows me to configure systems, troubleshoot problems, and simulate real-world IT support scenarios.

## Lab Environment

- Host Computer: macOS
- Virtualization Platform: UTM
- Client Operating System: Windows 11 Pro ARM64
- Current Workstation: `HELPDESK-WIN11`
- Local Administrator: `ITAdmin`

Additional Windows clients and Windows Server infrastructure will be added as the lab develops.

## Skills Being Practiced

- Windows 11 administration
- User and group management
- TCP/IP networking
- Command Prompt and PowerShell
- System troubleshooting
- Windows Server
- Active Directory Domain Services
- DNS and DHCP
- Group Policy
- File and NTFS permissions
- Help Desk ticket troubleshooting
